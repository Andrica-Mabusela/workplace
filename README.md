### Workplace Project
This project aims to evaluate the prices of different vegetables by determining whether or not the vegetable prices change by seasonality, in an attempt to provide cosumers/vegetable retailers with knowledge of when is the best season to purchase these vegetables.

## Installation
1. Clone the repo
   ```bash
   git clone https://github.com/Andrica-Mabusela/workplace.git
   ```
2. Create and activate a virtual environment, if necessary
    * On macOS/Linux:
        ```bash
        python3 -m venv venv
        source venv/bin/activate
        ```

    * On Windows:
        ```bash
        python -m venv venv
        venv\Scripts\activate
        ```

3. Then, install the packages:
    ```bash
   pip install -r requirements.txt
   ```


## Usage
open main.ipynb notebook and click on 'Run All' to run all the notebook cells
